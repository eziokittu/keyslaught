For a mobile survivor-like game like vampire survivors, or survivor.io, there can be many more cool feature that could be built. 
To pick one of them i would go with a base building mechanism. Say I am considering vampire survivors (have played hundreds of hours and completed most of the game). in this game the player is the only one who is attacking without any support. So we can have a base building mechanism to build a protected area and place defenses. That would make things so much more cool (like SAS: Zombie Assault 4, or Zombie Defense) the defenses and base can have their own upgrades. We can either have a build menu in game UI clicking which we can bild defences/traps/walls/baits/bombs ... or we can also put things in the game world itself where we can move the player and repair those units to make them working.
